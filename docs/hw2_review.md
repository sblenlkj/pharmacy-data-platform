## Ограничения

- Snapshot-гейт cdc-init пока использует стабильность offsets; явный
  Debezium snapshot-completed сигнал не добавлялся. На медленном стенде
  обязательно проверьте полноту исходного снимка официальным чекером.
- Поддерживается одна партиция на топик; физический DELETE вызывает ошибку.
- Iceberg-коммиты таблиц не образуют общей транзакции. До повторной
  успешной загрузки после сбоя DDS может быть частично обновлён.
- Lock действует для tools одного репозитория, не для разных машин.
- Работа SQL ограничивает вход raw окном и обновляемые ключи DDS,
  но не обещает отсутствие полного сканирования накопленного current state.
  Стоимость JOIN и тайм-аут 90 секунд требуют реального измерения.
